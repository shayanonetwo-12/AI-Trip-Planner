# 📖 Overview

AI Trip Planner is an intelligent travel planning web application that generates personalized travel itineraries using Artificial Intelligence.

Simply enter your destination, travel duration, budget, and travel preferences, and the AI instantly creates a complete trip plan including hotels, attractions, activities, and daily schedules.

Designed with a modern responsive interface, the application helps users save hours of planning while discovering amazing destinations around the world.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/shayanonetwo-12/AI-Trip-Planner.git
```

Move inside project

```bash
cd AI-Trip-Planner
```

Install dependencies

```bash
npm install
```

Start development server

```bash
npm run dev
```

Build project

```bash
npm run build
```

---

# 🔑 Environment Variables

Create a `.env` file

```env
VITE_GOOGLE_GEMINI_API_KEY=

VITE_GOOGLE_PLACES_API_KEY=

VITE_FIREBASE_API_KEY=

VITE_FIREBASE_AUTH_DOMAIN=

VITE_FIREBASE_PROJECT_ID=

VITE_FIREBASE_STORAGE_BUCKET=

VITE_FIREBASE_MESSAGING_SENDER_ID=

VITE_FIREBASE_APP_ID=
```
