# 🌎 Overview

**AI Trip Planner** is a modern AI-powered travel planning platform that helps users create complete travel itineraries in seconds.

Instead of spending hours researching destinations, hotels, attractions, and activities, users simply provide their travel preferences, and the AI generates a personalized travel plan instantly.

The application combines **Google Gemini AI**, **Google Places API**, **Firebase**, and a modern React frontend to deliver a seamless travel planning experience.

# 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/shayanonetwo-12/AI-Trip-Planner.git
```

Move into the project directory

```bash
cd AI-Trip-Planner
```

Install dependencies

```bash
npm install
```

Run locally

```bash
npm run dev
```

Build for production

```bash
npm run build
```
